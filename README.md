# 소셜 다운로더 (안드로이드)

링크만 넣으면 영상·사진·소리·파일을 휴대폰에 저장하는 IDM 스타일 다운로더 앱입니다.
인스타그램·X·스레드·틱톡·RedNote·유튜브 등 1,800여 개 사이트의 공개 콘텐츠와 일반 파일 링크를 받습니다.
다운로드 엔진(yt-dlp·ffmpeg)이 휴대폰 안에서 직접 돌아가므로 서버가 필요 없습니다.

## 내려받기
**[최신 버전 받기 →](../../releases/latest)**

- `SocialDownloader-x.y.z.apk`: 거의 모든 휴대폰(64비트, Android 10 이상)용
- `SocialDownloader-x.y.z-32bit.apk`: 위 파일이 설치되지 않는 구형·저가폰용

## 설치
1. 위 링크에서 휴대폰으로 APK를 받습니다.
2. 파일을 누르고, "출처를 알 수 없는 앱 설치 허용"이 뜨면 허용합니다.
3. Play 프로텍트 경고가 나오면 "무시하고 설치"를 누릅니다. 개인 서명 앱이라 뜨는 경고입니다.

새 버전이 나오면 앱 첫 화면에 알림이 뜹니다. 기존 앱 위에 덮어 설치하면 됩니다.

## 주요 기능
- **공유로 받기:** 다른 앱에서 공유 → 「소셜 다운로더」를 누르면 화면 전환 없이 알림창에서 받아집니다.
- **다운로드 관리:** 여러 링크 한 번에 넣기, 동시 다운로드, 분할 가속, 일시정지·이어받기
- **미리보고 받기:** 화질별 예상 용량을 보고 고르기, 재생목록에서 골라 받기, 구간만 받기
- **받는 형식:** 소리만 MP3(앨범 표지 포함), 자막 넣기, 제목으로 파일 이름 저장
- **앱 안 브라우저:** 영상 감지, 광고 차단, 페이지 사진 모아 받기
- **그 밖에:** 받은 파일 검색·관리, 홈 화면 위젯, 빠른 설정 타일

## 받을 수 없는 것
- DRM으로 보호된 영상(넷플릭스·티빙 등)
- 로그인·유료·비공개 콘텐츠
- 받은 콘텐츠는 개인 소장용으로만 쓰세요. 재업로드·상업적 이용은 저작권 침해가 될 수 있습니다.

이 저장소에는 배포용 APK만 올라갑니다. 앱은 오픈소스 [yt-dlp](https://github.com/yt-dlp/yt-dlp)와 [youtubedl-android](https://github.com/JunkFood02/youtubedl-android)를 사용합니다.
